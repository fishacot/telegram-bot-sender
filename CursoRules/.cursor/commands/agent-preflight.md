# Agent preflight

Использование: добавьте этот файл как **Custom Command** в Cursor (имя команды задаётся в UI) или выполните шаги ниже в чате с агентом вручную. Канон проверок — `AGENTS.md` → **Verification**.

Перед изменениями в репозитории (опционально сначала Custom Command **agent-task-intake**, если запрос «сырой»):

1. Кратко перечисли, **какие файлы** тронешь и зачем (без лишнего).
2. Проверь: задача не требует CLI **claw** из чужого репо — если не просили, не предлагай.
3. Открой `AGENTS.md` → **Verification**; после правок выполни **`npm run verify`** (и `npm install` при необходимости).
4. Затем делай минимальный diff и снова сверься с Verification.
