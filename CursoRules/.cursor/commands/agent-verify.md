# Agent verify

В корне репозитория выполни:

1. При первом запуске или после смены зависимостей: `npm install`
2. `npm run verify`

Интерпретируй вывод: ноль ошибок — ок. При ошибках исправь Markdown или конфиг `.markdownlint.yaml` осознанно. Канон шагов — `AGENTS.md` → **Verification**.
