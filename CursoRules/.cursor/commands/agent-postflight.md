# Agent postflight

1. Перечисли изменённые файлы и связь с запросом человека.
2. Если есть `.git` — опционально покажи суть изменений (`git diff` / список файлов).
3. Запусти `npm install` при необходимости, затем **`npm run verify`**.
4. Кратко отметь выполнение пунктов **Definition of Done** из `AGENTS.md` и **приёмки** (acceptance), если она была задана.
